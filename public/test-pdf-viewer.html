🔧 Test de Correction - Flash PDF Viewer

Problème identifié

Bug : Le PDF clignote/flash quand le curseur se déplace dessus

Cause : La fonction addWatermark() recréait tous les filigranes à chaque appel, provoquant des modifications DOM répétées

Corrections appliquées

  • Ajout d'une variable watermarkCreated pour éviter les recréations
  • Vérification avant création : si déjà créé, on retourne immédiatement
  • Ajout de will-change: transform pour optimiser les performances CSS
  • Ajout de backface-visibility: hidden sur le watermark overlay
  • Ajout de transform: translateZ(0) sur le canvas pour activer l'accélération GPU
  • Optimisation du rendu pour éviter les repaint inutiles

✅ Tests à effectuer

  1. Ouvrir la page : http://0.0.0.0:8000/formation/2/module/2
  2. Cliquer sur le bouton "Voir" d'un contenu PDF
  3. Attendre le chargement complet du PDF
  4. Déplacer le curseur sur le PDF
  5. Vérifier qu'il n'y a PLUS de clignotement/flash
  6. Naviguer entre les pages (boutons < >)
  7. Zoomer/dézoomer (boutons + -)
  8. Vérifier que les filigranes sont toujours visibles
