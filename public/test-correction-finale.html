Correction Flash PDF Appliquée

7 corrections majeures ont été implémentées

Problème Résolu

Bug initial : Le PDF clignotait/flashait en permanence quand le curseur se déplaçait dessus, donnant l'impression que le PDF essayait de s'ouvrir dans la card au lieu du modal.

Corrections Appliquées

1. Protection contre la recréation des filigranes

Variable watermarkCreated empêche les recréations infinies

2. Délai d'initialisation du modal (100ms)

Le PDF ne se charge que lorsque le modal est complètement stable

3. Blocage des événements de hover

stopPropagation() sur mouseenter, mouseleave, mousemove

4. Utilisation de requestAnimationFrame

Synchronisation avec le rafraîchissement de l'écran pour un rendu fluide

5. Isolation CSS complète du modal

z-index: 9999, isolation: isolate, contain: layout style paint

6. Accélération GPU activée

transform: translateZ(0), will-change: auto

7. Optimisations Canvas & Watermark

backface-visibility: hidden pour éliminer les artefacts visuels
