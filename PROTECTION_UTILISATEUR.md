# 🔒 Protection du Contenu - Guide Utilisateur

## Pourquoi ces protections ?

Le visualiseur PDF de Colibri Littéraire est protégé pour respecter les droits d'auteur et protéger le travail des auteurs africains. Ces mesures garantissent que le contenu reste accessible uniquement aux personnes autorisées.

---

## 🚫 Actions Bloquées

Lorsque vous consultez un PDF dans notre visualiseur sécurisé, les actions suivantes sont **automatiquement bloquées** :

### 1. **Captures d'écran**
- ❌ Touche `PrintScreen` (Windows)
- ❌ `Cmd + Shift + 3` (Mac)
- ❌ `Cmd + Shift + 4` (Mac)
- ❌ `Win + Shift + S` (Windows)
- ❌ Outils tiers (ShareX, Lightshot, etc.)

**Ce qui se passe :** L'écran devient noir automatiquement et un message d'alerte s'affiche.

### 2. **Enregistrement d'écran**
- ❌ OBS Studio
- ❌ Bandicam
- ❌ QuickTime (Mac)
- ❌ Windows Game Bar
- ❌ Tout autre logiciel d'enregistrement

**Ce qui se passe :** L'accès à la capture est refusé avec un message d'erreur.

### 3. **Copier-Coller**
- ❌ Sélection de texte
- ❌ `Ctrl + C` / `Cmd + C`
- ❌ Clic droit → Copier

**Ce qui se passe :** La sélection est impossible et le presse-papiers reste vide.

### 4. **Impression**
- ❌ `Ctrl + P` / `Cmd + P`
- ❌ Menu Fichier → Imprimer
- ❌ Impression PDF

**Ce qui se passe :** L'impression est complètement désactivée.

### 5. **Téléchargement**
- ❌ `Ctrl + S` / `Cmd + S`
- ❌ Clic droit → Enregistrer sous
- ❌ Extraction du fichier

**Ce qui se passe :** Aucune sauvegarde n'est possible.

### 6. **Outils de développement**
- ❌ `F12`
- ❌ `Ctrl + Shift + I` / `Cmd + Shift + I`
- ❌ `Ctrl + U` (code source)
- ❌ Console développeur

**Ce qui se passe :** Un avertissement plein écran s'affiche et bloque l'accès.

## ⚠️ Comportements Normaux

Certains comportements peuvent vous surprendre, mais sont **normaux et voulus** :

### L'écran devient noir
**Quand ?**
- Vous changez d'onglet
- Vous minimisez la fenêtre
- Vous cliquez en dehors du navigateur
- Vous appuyez sur PrintScreen

**Pourquoi ?**
Ces actions peuvent être liées à une capture d'écran. Le contenu est masqué par sécurité.

**Solution :** Cliquez simplement sur la fenêtre pour restaurer le contenu.

### Message "SESSION SUSPENDUE"
**Quand ?**
Lorsque la fenêtre perd le focus pendant plus de 50ms.

**Solution :** Cliquez sur la fenêtre du PDF pour continuer la lecture.

### Avertissement "DevTools détecté"
**Quand ?**
Si vous ouvrez les outils de développement du navigateur.

**Solution :** Fermez les DevTools (F12) pour continuer.

### Message "Accès expiré"
**Quand ?**
Après 14 jours depuis la validation de votre emprunt.

**Solution :** Contactez l'administration pour une prolongation.

Vous remarquerez des watermarks semi-transparents :

## ❓ Questions Fréquentes

### Puis-je lire hors ligne ?
❌ Non, le PDF n'est jamais téléchargé sur votre appareil. La lecture nécessite une connexion internet.

### Puis-je partager mon accès ?
❌ Non, votre compte est personnel. Le partage est interdit et tracé.

### Puis-je utiliser une machine virtuelle ?
❌ L'utilisation de VM pour contourner les protections est interdite et peut être détectée.

### Que se passe-t-il si je prends une photo avec mon téléphone ?
⚠️ Les watermarks avec votre ID seront visibles sur la photo. Cela constitue une violation des droits d'auteur.

### Mon accès expire dans combien de temps ?
Vous pouvez voir le temps restant sur la page "Mes Emprunts" avec un compte à rebours en temps réel qui affiche les jours, heures, minutes et secondes restants. Le badge change de couleur selon le temps restant :
- 🟢 Vert : Plus de 2 jours restants
- 🟡 Jaune : Moins de 2 jours restants
- 🔴 Rouge : Moins d'1 heure restante

### Les protections ralentissent-elles la lecture ?
Non, les protections sont optimisées pour ne pas affecter les performances.

## 🚨 Violations et Conséquences

Toute tentative de contournement des protections peut entraîner :

1. **Blocage immédiat** de votre compte
2. **Révocation** de tous vos emprunts en cours
3. **Interdiction** d'emprunter à l'avenir
4. **Poursuites légales** selon la loi sur les droits d'auteur

### Comportements interdits
- ❌ Utiliser des outils de contournement
- ❌ Partager le contenu sur les réseaux sociaux
- ❌ Photographier l'écran
- ❌ Modifier le code JavaScript
- ❌ Utiliser un proxy ou VPN pour masquer l'identité
