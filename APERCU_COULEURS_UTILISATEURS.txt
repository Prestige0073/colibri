CODE PHP - CALCUL DE LA COULEUR
═══════════════════════════════════════════════════════════════════════════════════════════

@php
    // Palette de 8 couleurs Bootstrap
    $colors = [
        '#0d6efd', // primary
        '#198754', // success
        '#dc3545', // danger
        '#fd7e14', // orange
        '#6f42c1', // purple
        '#d63384', // pink
        '#20c997', // teal
        '#0dcaf0'  // info
    ];

    // Rotation basée sur l'ID utilisateur
    $userColor = $colors[$user->id % count($colors)];
@endphp

EXEMPLES:
User ID 1  → 1 % 8 = 1 → $colors[1] = #198754 (vert)
User ID 5  → 5 % 8 = 5 → $colors[5] = #d63384 (rose)
User ID 12 → 12 % 8 = 4 → $colors[4] = #6f42c1 (violet)
